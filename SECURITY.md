# Security Policy

## Scope

`InternedStrings` is a thin SwiftPM re-export wrapper over `Aemi-Studio/aemi`'s `InternedStrings` product. Report implementation vulnerabilities against `Aemi-Studio/aemi` or this repository.

## Supported Versions

Security fixes land on `main` and the latest tagged release (when releases are published). Pin a specific tag or commit revision for reproducible builds.

## Reporting a Vulnerability

Report security issues privately via [GitHub Security Advisories](https://github.com/g-cqd/InternedStrings/security/advisories/new). Do not open public issues with exploit details or sensitive material. Include the commit or version, platform, and a minimal reproduction.
